# 页面功能对照

[返回交接导航](../guide.html) · [数据库字段对照](data-mapping.html)

这份交接保留当前页面设计。下列交互均运行在浏览器本地；后台是否已支持某项功能应按字段对照和后续接口设计确认。

<a id="alerts"></a>
## 告警列表与侧栏

打开 [告警列表](../index.html#/alerts)。点击告警名称打开右侧抽屉，再点击“打开告警页”进入完整详情。

| 区域 | 现有元素 / 操作 | 实现位置 |
| --- | --- | --- |
| 页头 | 告警和事件面包屑、告警标题、数量统计 | app.js |
| 工具栏 | 刷新、导出、最近 7 天、搜索名称或 ID、自定义列 | app.js |
| 快捷筛选 | 全部级别 / 高 / 中 / 低；全部状态 / 新建 / 进行中 / 已解决；全部告警 / 分配给我 | app.js |
| 其他筛选 | 添加筛选、条件标签、重置全部 | app.js |
| 表格 | 名称、严重程度、告警时间、资产标签、处理状态、类别、检测源、受影响资产、负责人 | app.js |
| 表格操作 | 只有严重程度和告警时间可排序；固定列宽；分页、多选、批量管理 | app.js |
| 侧栏 | 仅概览；严重程度、状态、战术、发生了什么、告警属性、实体、所属事件与 Case | app.js |
| 管理 | 状态、分配给、评论；不提供分类 | app.js |

告警时间默认最新在顶部。“分配给我”使用原型中的 Alex Wilber 身份，正式接入应替换为登录用户。6 条实际告警的负责人和资产关联为空；原始主机、账户、IP 可以显示，但不是已有资产台账链接。

<a id="detail"></a>
## 告警详情

打开 [一条实际处理结果](../index.html#/alerts/4c71eec2-77da-5b81-b68a-72801d55ea24/overview)，或 [未关联 Case 的设计样例](../index.html#/alerts/alert-unassigned-case-001/overview)。

| 页签 / 区域 | 内容与交互 |
| --- | --- |
| 页头 | 名称、严重程度、处理状态、检测置信度、风险评分；发起 AI 调查位于管理告警左侧 |
| 关联提示 | 所属事件保留，额外显示所属 Case；无 Case 明确显示未关联 |
| 概况 | 发生了什么（Explain 内容及建议动作）、告警属性、实体 / IOC、MITRE、相关告警、Case 与调查、判定与反馈 |
| 时间线 | 发生、入库、分诊、调查、分配、关闭等有记录的生命周期，最新在上 |
| 原始数据 | 可查看该告警原始字段与载荷 |
| 响应 | 简短响应建议与执行信息；下面保留自动处理过程、步骤、工具、发现、报告 |
| Case 关联弹窗 | 默认“关联到已有”；搜索名称或 ID，展示最近活跃的 7 个 Case；另有新建页签，无 Case 时可选且名称默认当前描述，已有 Case 时禁用新建 |
| 判定反馈 | 保留四种判定卡片与相似历史复核交互；实际写回流程待后续实现 |

相关告警描述为同主机最近 7 条。反馈复核候选描述为同主机同战术最近 5 条，以及使用同一 IP / 文件哈希 IOC 的最近 5 条；具体查询由后端实现。当前只对加载到页面的数据做展示。

<a id="incidents"></a>
## 事件

[列表](../index.html#/incidents)包含统计、搜索 / 筛选 / 时间范围、列设置、导出、单条 / 批量管理和预览摘要；点击名称进入详情。

[详情](../index.html#/incidents/262144/attack)保留攻击故事、告警、活动、资产、调查、证据与响应、建议动作、概览和相似事件。攻击图提供选择联动、筛选、分组、缩放、回放及潜在影响展示。关联告警和证据可继续打开。

本批只交付已设计的页面和样例交互，没有确认事件后台所有字段或流程。真实告警携带的事件 UUID 不会强行跳到样例事件 262144。

<a id="cases"></a>
## Case

[列表](../index.html#/cases)保留案件统计、列表、搜索 / 筛选、列设置及筛选集。未实现的创建 / 设置 / Generic 入口保持当前占位表现。

[详情](../index.html#/cases/17420/overview)保留概览、攻击关系图、告警、资产、相似 Cases、调查、证据、活动等当前导航，以及原型中已实现的评论和告警成员操作。部分栏目只有名称或样例内容，不能据此认定已接后端。

<a id="assets"></a>
## 资产及其他菜单

有资产库存 ID 的链接进入 [资产详情占位页](../index.html#/assets/d1)，按已确认设计仅显示大标题。没有库存关联的原始实体以文字显示。

侧边栏其他业务模块只保留名称。本包不扩展其页面。

## 阅读代码

所有页面共享同一个 index.html，通过 `#/...` 切换，不是每个页签一个独立 HTML。列表、事件、Case 和抽屉在 app.js，告警完整详情在 alert-detail.js；数据文件及 CSS 均在文件夹根目录。功能页上不额外添加字段编号或开发说明，避免改变原设计。

## 事件和Case的本批对齐

[微软产品及功能拆解](microsoft-incident-case-analysis.html)说明各区域、图谱节点/关系和按钮的业务含义。图谱关系支持来源查看、范围扩展及潜在影响路径；Case增加任务入口、负责人/期限/状态、结案说明，调查按当前告警成员变化。没有对应调查记录时显示空态。所有新写操作仍只保存浏览器本地数据；不提供真实权限图、查询、后台任务或处置能力。
