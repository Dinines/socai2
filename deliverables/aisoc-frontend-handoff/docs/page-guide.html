相关告警描述为同主机最近 7 条。反馈复核候选描述为同主机同战术最近 5 条，以及使用同一 IP / 文件哈希 IOC 的最近 5 条；具体查询由后端实现。当前只对加载到页面的数据做展示。

事件

列表包含统计、搜索 / 筛选 / 时间范围、列设置、导出、单条 / 批量管理和预览摘要；点击名称进入详情。

详情保留攻击故事、告警、活动、资产、调查、证据与响应、建议动作、概览和相似事件。攻击图提供选择联动、筛选、分组、缩放、回放及潜在影响展示。关联告警和证据可继续打开。

本批只交付已设计的页面和样例交互，没有确认事件后台所有字段或流程。真实告警携带的事件 UUID 不会强行跳到样例事件 262144。

Case

列表保留案件统计、列表、搜索 / 筛选、列设置及筛选集。未实现的创建 / 设置 / Generic 入口保持当前占位表现。

详情保留概览、攻击关系图、告警、资产、相似 Cases、调查、证据、活动等当前导航，以及原型中已实现的评论和告警成员操作。部分栏目只有名称或样例内容，不能据此认定已接后端。

资产及其他菜单

有资产库存 ID 的链接进入 资产详情占位页，按已确认设计仅显示大标题。没有库存关联的原始实体以文字显示。

侧边栏其他业务模块只保留名称。本包不扩展其页面。

阅读代码

所有页面共享同一个 index.html，通过 #/... 切换，不是每个页签一个独立 HTML。列表、事件、Case 和抽屉在 app.js，告警完整详情在 alert-detail.js；数据文件及 CSS 均在文件夹根目录。功能页上不额外添加字段编号或开发说明，避免改变原设计。

事件和Case的本批对齐

微软产品及功能拆解说明各区域、图谱节点/关系和按钮的业务含义。图谱关系支持来源查看、范围扩展及潜在影响路径；Case增加任务入口、负责人/期限/状态、结案说明，调查按当前告警成员变化。没有对应调查记录时显示空态。所有新写操作仍只保存浏览器本地数据；不提供真实权限图、查询、后台任务或处置能力。
