## 当前设计

事件列表右侧四项简写为**活跃事件、待分配、24h有新告警、高严重程度**，2026-10-31 12:00（上海）的样例为17/5/2/15，24h数字随当前时间变化；整体右对齐，右上角ⓘ悬停或聚焦可查看完整定义与统计范围。24小时按当前时间与告警发生时间计算，打开或刷新时更新；历史样例不改日期。事件缺失源状态按本地规则默认新建；原状态保留在数据来源中，不再作为顶部统计。

事件状态规则：默认**新建**；分配具体负责人后为**处理中**；仅人工选择并填写解决说明才能**已解决**。原来已解决的事件改负责人不会自动重开，AI调查结果不会自动关闭事件。管理仍仅本地保存，源记录缺状态不代表后端已接入此规则。

事件聚焦**是什么、为什么关联、有哪些关系**：概览顶部先显示ATT&CK阶段覆盖，再显示“事件是什么”、关联依据及告警时间线；关系图只放在“关联分析”，不在概览重复展开。当前页签为概览、关联分析、成员告警、涉及对象、处理活动；移除切换事件。共享对象可回查成员告警，未提供的归并规则保持未知。旧基础调查/调查/证据深链仍可读，旧事件chain链接兼容打开关系图。Case保留案件资料、成员、关系图、证据和协作；每次Run六个视图保持。

最新概览布局：**ATT&CK阶段覆盖放在“事件是什么”上方；说明、成员/资产计数、发生范围合为紧凑信息卡**；处理状态、负责人和更新时间只保留在页头，不再重复。撤下四张相近的大计数卡，对象总数留页签、共享数量留共同线索。“为什么关联在一起”内左侧时间线、右侧共同线索，窄屏上下排列。阶段数字仅为告警分类计数，不是检测覆盖率。

事件列表默认7列：事件名称、严重程度、状态、负责人、涉及资产、活跃/全部告警、最近更新时间；成员告警默认7项核心字段。完整低频字段仍在自定义列，已有选择保留。事件ID选配列缩略显示，悬停查看完整值，可复制完整ID，导出仍使用完整值。统计卡数量、右侧对齐和取值不变。

事件图谱统一使用**圆形节点、左告警 / 中图 / 右详情**，包括保存的AiSOC事件；范围固定为当前事件且不显示冗余范围提示，计数/筛选合为紧凑工具区，来源筛选称“数据来源”，撤重复大标题，画布上移；保留过滤、分组、布局、缩放、播放和来源查看。事件不再提供告警链、跨事件范围或潜在路径；Attack Chain和Attack Path保留在Case调查。实际事件只显示已有“告警—对象”连线，不补造实体间攻击行为。可对照[Office实际结果图](http://127.0.0.1:4174/#/incidents/85b81836-be47-4ab0-8c1f-6d360c5fb0a2/attack)与[原完整样例图](http://127.0.0.1:4174/#/incidents/337075/attack)。

深入判断进入Case：已有Case直接进入或选择；没有Case时显示**新建Case**，默认带入事件名称和全部当前成员，可切换关联已有Case。只有确认才本地创建/关联，不自动启动调查。按实际关联Run展示完整性，附件和任务初始为空，不把真实来源缺项补成演示材料。详见[单图与Case衔接](../../docs/design/incident-investigation-page-analysis.md#229-事件单一关系图与case入口)。

页面不再增加 AiSOC 来源页签、行副标、导入横幅或“本地整理”标题后缀。旧 `data=aisoc/design` 链接统一显示全部 Case；业务搜索、等级、状态等筛选保留。原始来源身份仍保存在数据中，用于同环境、同租户关联；此处列出来源供审计，不把来源说明塞进日常页面。

Run 是否结束、交付完整性、判定、停止原因和实际执行分别显示。保留 partial、查询失败、未关联及空值；去掉来源标注不等于补齐后台能力。管理仍仅在浏览器本地生效。
