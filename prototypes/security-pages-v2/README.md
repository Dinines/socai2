# AiSOC 当前页面

当前产品只维护这一套页面和一份完整产品需求。普通样例、AiSOC 保存记录及新建 Case 使用同一套读取和交互流程，缺少材料时使用统一空态。

## 产品需求

[告警、事件与调查产品需求说明](../../docs/design/alert-incident-case-product-requirements.md)是产品、设计、研发和验收的统一入口，包含页面功能、按钮行为、跳转链接、业务规则、完整示例与未解决事项。基础调查、AI 对话调查与人工任务按当前规则统一描述；溯源分析等尚未解决的方向集中记录在后续事项中。

## 完整结果示例

- [财务终端：案件资料](http://127.0.0.1:4174/#/cases/outcome-case-01/case-info)：首次调查、加入登录告警后的更新、人工确认、已保存AI结论与当前案件判断。
- [财务终端：故事与助手](http://127.0.0.1:4174/#/cases/outcome-case-01/story)：点击“询问整个案件”，选择建议并发送，查看结果后“保存到调查记录”；可回查对话、引用调查和当时人工结果。
- [报表服务账号：调查概览](http://127.0.0.1:4174/#/cases/outcome-case-02/overview)：部分结果、补查失败、唯一执行中的调查和人工任务。

这两组新增展示数据为独立样例，与实际来源共用页面和结果读取；示例助手使用本地预置返回，没有真实模型或工具调用。AiSOC实际记录不填入示例结论，未接分析服务时显示不可用与重试。已有AiSOC案例仍可从上表进入。

## 本地启动

在本目录运行 `python3 serve.py --port 4174`，只监听本机。已有页面刷新后加载当前脚本，不需要重置数据。现有目录名和本地存储键保留用于兼容已有链接和编辑记录，不代表并行维护多套产品版本。

当前初始数据为 94 条告警、27 个事件、25 个 Case、27 个 Run，其中 13 个 Run 是实际保存结果。已有浏览器数据可能因本地编辑与初始数量不同。刷新追加样例，不覆盖历史编辑；请勿用重置操作清除用户数据来对齐数量。
