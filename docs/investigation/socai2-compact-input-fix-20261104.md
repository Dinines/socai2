## 体积和效果的边界

最初纯排布实验的 20.71%/19.52% 是**只去重复元数据**的结果。正式 n9 增加完整分诊、时间与可见性后，两份固定 I 请求数据分别为 7,891/7,937B，旧版为 7,860/7,960B。完整请求含 system 和 Schema 后为 13,445/13,423B，旧版为 13,340/13,684B。不能宣称实际总请求都缩小20%；本次首先解决的是在相同额度内完整携带必要内容。

7份旧答仅做离线重解析：4份合同接受、3份仍拒绝；新增接受的是原r5 A0的合法绑定正文编号，其余事实质量不由此证明。r4的背景成员错配、未知/未绑定引用和单发现冲突仍拒绝。原答、用量和旧结果不修改。

本地受影响检查最新通过：43项纯检查、6项验收驱动检查及16个不同PG方法。PG使用既有独立 `socai2_schema_review_20261103_a1`，模型/湖为替身；角色和隧道清理。初次旧断言、驱动导入、C6容量、时间引用白名单及新r6容量回归失败均保留，不能描述为一次全绿。详见[本地回执](../operations/socai2-compact-input-fix-20261104.json)。
