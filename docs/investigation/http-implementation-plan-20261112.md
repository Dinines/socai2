## 复用现有接口，不重复建功能

告警/事件详情的对象、来源、相关 Case，以及调查故事、历史结果、步骤、报告和人工任务，可以组合现有 GET。后端需要明确组装顺序和缺值处理，但不因一个页面有多个区块就新增一套保存流程。已有报告正文可以直接下载；需要统一附件服务时再纳入上表第 5 项。

图布局、缩放、折叠、聚焦、列显隐、当前选择和手动刷新属于前端交互；只有“跨设备保存偏好”“完整服务端过滤”等明确需求才设计持久化接口。F09-11 中未定义具体操作的“管理设置”、助手建议问题等先登记，不据一个按钮名称扩展功能。

## 交给业务后端的范围

- 资产库存、标签维护、人员目录及完整资料由业务后端实现；调查服务只按合同读取真实匹配。不存在“复制旧 AiSOC 全部资产表”的任务。
- F27-03 的审批、意见链和真实响应执行由业务后端承接；调查服务提供建议及已有回执读取，不把建议当执行成功。
- D07 保持：未解决问题是调查结论的一部分；需要人工确认时由用户创建任务，不新建问题管理、自动去重合并或自动任务流。
