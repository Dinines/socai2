# C173 未升级调查联验

2026-11-21，在 21 的独立候选库完成迁移 135、分诊保存与调查运行接口读回。候选 HTTP 与分诊服务使用同一版实现。本次功能随后在 21 正式发布。[正式发布和实际读回](../c173-escalation-release-20261121-04/README.md)

| 场景 | 实际结果 |
| --- | --- |
| 新选真实告警 | 从现有历史湖选取 1 条此前联验未使用的真实告警。核对原件版本后接收并调用项目模型分诊。材料、分诊与 Run 绑定通过，模型原答、数据库决定与候选 TCP HTTP 一致。该样本没有触发不升级决定，统计为 0。 |
| 明确不升级及排除项 | 使用合成模型回复和实际 PostgreSQL 验证，置信度 0.85 的完整正常结论保存 `not_escalated`，低于门槛、待复核、仍需核实和截断的回复均保留空值。 |
| 目录规则 | 使用实际 PostgreSQL 与 HTTP 适配层验证，同一 Run 关联多个 Case 时只计一次，统计按筛选范围跨页一致，历史及无匹配记录正确返回空值或 0。 |
| 数据库增量 | 在候选库核对 135 约束与表结构。初次合成正例揭示冻结规则需要允许随运行结束写新字段。修正后正例复验通过，迁移前后的已有 Run 内容一致。 |
| HTTP 合同 | 与 C173 正式 OpenAPI 对照，`GET /api/v1/socai2/analysis-runs` 参数和既有响应字段一致，新增项为 `statistics.not_escalated_count` 和 `items[].escalation_decision`。 |

安装器及模型边界的定向测试 24 项通过、3 项跳过，OpenSpec strict 及 Ruff 通过。另有两项全量 HTTP 边界检查在未修改基线也失败，涉及既有日志模块导入和事件页面 DTO 快照。

真实正例本批未观测到。真实原件、模型原答、失败检查和逐值回执留在 21 的本批私有目录。接口接法见 [统一分析记录查询](../../../integration/run-directory-http.md#未升级调查)。
