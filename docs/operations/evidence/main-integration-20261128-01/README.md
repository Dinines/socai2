# 完整 main 源码交付核对

本批按负责人明确要求整合 socai2 与 SpiritHub main，并补齐各组件发布方法。范围是已经实现的完整生产源码及其直接依赖，不限于先前的局部执行器发布补丁。线上业务与模型结果按各自原批次保留，本记录不重新认定模型正文质量或整个 OpenSpec change 完成。

## 版本与范围

- socai2 整合前为 V1.1 `6282e34db69eb0072044809b0418a9ccba3ae9fe`；远端 main 基线 `875ed7226e4e125d01bfc2bbc2d46ac0f5edd1fd`，是该分支祖先。既有分支上的输入过滤和计量依赖一起进入 main。
- SpiritHub 整合前远端 main 为 `83a4f5ef3fd893aa7f49f6c71c852cce7428b818`；实际 8181 源树先冻结为 `837ea61608807fe191fb20f13e2cccecc19fa76f`。独立普通工作树做三方整合，原开发工作区保留。
- 父 main 原 `server` 对象不能从配置的 child 远端取得。本次引用必须更新为实际已推送并读回的 socai2 提交；最终两个提交号及 gitlink 以本批 Git 远端读回记录为准，不在提交内容中填自引用 SHA。
- 生产源码、测试、合同/配置示例、迁移、构建入口和手册纳入。实际运行配置、凭据、模型/数据库原件、生成查阅快照留在受控位置。4173 录制及混合演示修改整组保留本机，不影响生产包完整性。独立 OCSF 转发实机目录和 Dashboards 运维修补不夹带到本批。

## 合并的必要校正

平台使用当前原生调查 HTTP 的真实路由与响应，保留事件诊断摘要、活跃成员数、检测源以及 Case 资料/历史字段。已退役的公开 prepare/start 和手动告警执行入口不复活；未实现的旧 Q 声明撤下，实际页面依赖按保存身份和已有正式读取入口接线，缺少身份明确不可用。Case 对象沿 main 既有范围/版本检查，不增加样本匹配、回填或本地虚构数据。

通用 Run 保留主线的告警/事件/Case 权限语义，并校验返回的父 Run 和步骤身份。共享类型由最终 Schema 生成，非 SOC 方法及其可达组件与远端 main 作结构比较；非 SOC 路由和资源保持。平台桥接配置随 Settings、示例、Compose 和 Nginx 同步，最大响应字节的容器透传缺口已由独立源码复核关闭。

原生 HTTP 的日志调用移到既有 adapter 层，logger、事件名、5xx 阈值、错误字段、异常结构和响应不变。老合同快照漏记的已提交增量按明确字段/类型/约束断言后归一化，保留其余路径及组件完整比较，未以新默认值或宽泛忽略掩盖合同变化。

## 验证口径

复用既有模块验收及匹配源码指纹，仅对本次组合和冲突解决运行直接检查。测试替身、Schema/源码检查与真实业务读取分开记录。源码审查及直接检查摘要见同目录 `review.json`；中间失败与完整命令日志在本机该批私密目录保留，不包含到公开源码包。

Git 内公开的是非私密源码、Schema、路径/指纹清单和经过审查的离线工程记录。历史文档中指向运行批次的链接可对应受控本机证据；没有将请求、配置、原答或数据库快照复制进 Git，也没有删除原件来使工作区看起来干净。
