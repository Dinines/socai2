# C3历史选择与C6引用反馈：离线修正

2026-11-13。本轮只修改程序输入选择和一次纠错的反馈材料，复用固定05批原件；没有模型、网络、HTTP或数据库调用，没有新Run、部署、流式行为或表/接口合同变更。主调查仍31/41，真实模型质量仍未通过。

## 已修的具体缺口

**C3按单条历史材料判断是否有用。** 原实现按整组决定保留，历史判断/人工正文会连带保留纯目录；子依据已经独立可见时，父目录还会因路径前缀被当成必需。现在按条选择，子依据的可见性按类型/身份/角色/路径核对；纯目录没有独立用途时不选，直接引用或承载尚未独立可见的必要子依据时仍保留。未知业务扩展、0/false/有效空列表及人工反证保持。

这不是直接删除出错的 `N3_S238`：前序I的 `N3_S97` 明确引用它，必须保留以便核查I。现在将案件外及主体未核实的历史分别分组，案件外行写明“原主体=X1；不证明本案成员事实”，不再笼统列成案件背景。相关历史判断原文及案件外身份保持，不将其提升为本案依据或知识适用范围。

**C3/C6对局部引用错误只给局部反馈。** 当错误只有重复引用或成员错配时，反馈包含错误字段、当前引用数组，以及重复编号或来源的原角色/主体；原始材料和完整前一答已经在同一对话，不再重发全部来源/发现目录。C6的具体错误现在直接指出 `recommendations[1].source_ids` 中 `N6_S9` 重复。C3错配反馈要求依据本案材料重新核对主张，不能只删号保留无据断言。混合其他错误时继续完整诊断，不增加调用或预算。

模型原答不由程序去重、补引用或改写。严格接收器、局部保留、保存和采用规则未变；这里只改善程序选材和反馈，不能保证模型下一次会纠正。
