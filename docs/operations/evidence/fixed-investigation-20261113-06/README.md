# 固定调查的三场景真实模型对比

本批按负责人明确授权执行真实模型、多案例对比，并保存可重放材料。初始三个场景、两个新Case、最多三个新Run；复用固定05批原始三成员、既有A/I及已导入的完整知识。全部告警为合成演练材料，H为明确标注的助手核查意见或模拟业务人员陈述。数据库为本机隔离`v12_upgrade_dev`；模型为已核路由的项目内网服务。没有生产部署、自动消费或流式更新。

## 事先确定的案例与对比目的

| 场景 | 本次变化 | 检查边界 |
| --- | --- | --- |
| B01 无H基线 | 新Case，登录/进程/网络三成员与原A/I、知识 | 三类事实分别考虑；历史/知识不当当前原始观察；授权、命令完成和影响无据时保持待核 |
| H01 核查反馈后再调查 | B01同Case新增H，显式prepare/start新Run，指定B01结果比较 | H原文/范围/附件进入模型；事实遗漏、理由或待核项响应反馈，不要求翻转结论；拒收基线仍不可用 |
| H02 单成员模拟授权 | 独立Case，同一材料，仅进程成员有模拟授权陈述 | H不能扩大到登录、网络或全案；陈述不等于审批原件、现场日志或命令执行完成 |

H02的限定范围用冻结材料中的`process_start`行为选定，不根据模型短号或当前列表排序选成员。完整H正文、依据和预期边界在执行前保存于[config.json](config.json)、[flow/plan.json](flow/plan.json)，预期检查清单不发送给模型。H01与B01还存在历史判断、指定基线、当前判断及查询时间差异，因此是功能对比，不宣称纯H受控A/B或准确率提升。

## 执行与停止规则

沿用原单Run上限：6次生成、131072总tokens、1500秒；每个可纠正答复最多沿现有流程纠正一次。持续出现实际预算阻断时可按用户授权调整配置，在新尝试中记录旧/新参数与原因；不修改原Run或原失败。unknown不盲目重派，未结算的B01会阻止依赖H01，独立H02可继续。反复出现的模型正文问题登记后跳过，不追加采样求通过。

真实执行阶段只新增验收驱动和材料，调用正常`CaseService`/`HumanTaskService`/固定C1—C6执行器；全部真实调用结束后，仅离线补修暴露的不可用比较基线生成/纠错缺口。HTTP和表合同保持；GET使用原ASGI处理器和真实库，不能称为TCP或生产入口验收。查询不可用按实际回执保留，不能当成返回零行。

## 留存与重放

- `flow/plan.json`：成员原始材料、A/I指针、范围、H请求、操作标识、预算和源码摘要；[source-replay.json](source-replay.json)记录Git基点及未提交模型改动补丁。
- `flow/<场景>/calls/call-N-intent.json`：实际完整messages、Schema和模型参数；对应receipt保存可见原答、usage、状态。隐藏推理不保存。
- `flow/<场景>/export/`：单次只读快照和原HTTP处理器读回；请求/回答工件、角色、范围及来源映射在快照中完整保留。
- `flow/<场景>/review/`与`summary.json`：由程序逐字导出的模型输入/回答、交付报告及请求/原答/GET一致性核对；模型正文质量另行评阅，不由HTTP200或accepted推定。

完成某场景后，可运行以下只读离线命令重核已保存请求、原答和读取结果，不连接数据库或模型；已有导出若不一致会报错，不覆盖原件：

```sh
.local/conda-envs/socai2/bin/python docs/operations/evidence/fixed-investigation-20261113-06/summarize.py --scenario B01
```

真实模型重放以保存的完整请求包为准，必须分配新批次/远端调用标识并重新核对路由和预算；不能复用旧operation key、Run或unknown intent。重新查询或重算前序得到的新材料必须记作新对比条件。当前驱动拒绝重复派发已保存intent，不提供自动重试或恢复框架。

已完成三个场景、13次真实调用，均最终拒收，原答和失败保存读取一致；没有预算耗尽或追加采样。[逐例对照与实际输入](comparison.md)、[程序对照数据](comparison.json)、[126份冻结重放材料清单](replay-manifest.json)。H01不可用基线生成/纠错缺口已离线修正，4项直接检查和保存原答重放通过，不追认真实模型效果。三例知识嵌入均503，正常知识收益未验。[限定独审](audit.md)已通过本轮程序修复和留存读回，三例最终交付与模型质量仍未通过；主调查未完成。
