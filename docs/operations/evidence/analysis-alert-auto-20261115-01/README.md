## 实施结果

正常原生入站在同一PG事务保存告警、材料、事件成员及唯一initial任务；重复投递保留原件，不产生再次分诊。调度器读取持久任务，经统一Redis队列调用现有A执行器。执行前读取最新材料，Run/输入/策略与attempt在同一事务保存，然后才查询背景和调用模型。已知发出前连接超时可有限重试，响应超时保留unknown并释放本地名额，后续任务继续执行。

对外告警字段未改；HTTP侧已删除目标E36手动分析入口和外部A执行分支，内部A能力保留。投影topic/group/路径/时限和A执行器工厂采用显式配置，源代码打包、启动挂载、新装/升级入站授权同步。默认运行profile仍禁用，不能把本地代码完成当成生产自动消费已开启。
