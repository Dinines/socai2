C6 保留全案业务事实、C3 业务结论、两个原 Deep 回答、必要依据和待核事项，去掉程序负责的 coverage 答案、重复原计划及执行台账。查询只给结果，知识保留实际条件和正文；两个旧 JSON 知识片段仍保持原样，本批没有替换成上批的新导入合成资料。

两个环节各移除160条无业务内容且未被必要前序引用的历史目录，保留103/118个来源；12/65项结构化前序依赖全部恢复。支持/反证、历史主体、原范围和原文均核对保持，不能把减少体积当成模型质量通过。A/I 总体引用在后续环节也已恢复到当前短号，HTTP字段、表结构和输出保存读取合同不变。
