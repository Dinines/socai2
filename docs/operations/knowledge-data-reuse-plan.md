## 本轮最小实施

1. 优先只读确认20上一版已采集资料的位置、格式、已有索引及来源元数据，再选少量固定来源ATT&CK/runbook/报告片段核已有检索路径；历史经验新增整理后看。已接组织记忆、技能、KB/处置/身份读取保留，不重复逐项专项验收。
2. 对照真实调用链确定使用PG全文还是向量召回；二者原实现保留，不先统一知识框架。向量路径若被使用，最小对齐实际embedding路由、模型/维度和项目集合。API默认1536与现有1024不一致须按实际空间适配，不能靠padding冒充同一模型空间。
3. 只将所需资料写入隔离的项目对象，保来源/版本/tenant与引用；不覆盖旧索引，不将2560与1024混写，不先嵌入全部40万行。
4. 在B2已有调查链中调用检索，核资料实际进入同Run的模型材料与报告；自动调查B4复用同一消费证据，仅补实际差异。
5. 验证仅针对这次适配：来源→检索→实际采用→引用可定位，再补必要无匹配/缺源状态；原样整体依赖不新增独立测试，不做模型大矩阵。

## 完成与保留边界

完成要求实际调查消耗所用资料并可追溯，不能以向量存取成功或prompt含块名当引用质量通过。缺源如实partial，不据此判定安全或授权。知识/TI支撑服务若确为调用必需，按原组件边界整体迁入及最小接入，不要求全商业Feed/所有外部渠道。

自动经验写回/反馈闭环、4B评测、全量知识导入和性能专项后置；一体实现原样保留，不额外改测。费用未知仍记unknown，当前计划不改变模型、数据、索引或运行配置。
