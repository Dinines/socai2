固定合成样例：恶意活动的具体证据、带变更单背景的有效检测、材料不足、一次独立模型网络失败。授权背景是输入提供的合成事实，未连接外部审批系统；须检查实际prompt是否包含这些材料，不把外部真实性写成已核实。读取失败与空材料分别记录；没有普通事件/UEBA来源，不得据此推断无异常。

三条正常样例分别保留实际调用prompt/响应hash、模型alias/实际路由、解析前后verdict、置信和简短证据依据、usage、事件/工件/Run及告警关系。预先期望：恶意需保留风险/复核；授权应能区分有效检测与恶意（未核实允许needs_review）；材料不足不得高置信自动关闭。实际结果不符合就保留失败，不按期望改模型响应或覆盖历史Run。

模型失败仅改变独立进程的模型目标到本地闭合端口，不停止共享网关/43；核生产fallback实际被调用、严重告警保持复核、模型成功计数不增，费用未知不记零。
