## 统一阅读方式

本目录提到的“主文档”均指[页面功能与展示要素建议](../page-elements.md)。

- 深色条是一级菜单；蓝色条是当前页签；橙色是需注意的状态；灰色是空态、补充信息或明确的开发版说明。颜色都同时配文字。
- 方框仅对功能要素作阅读分组，连线只为排版；位置、大小、排列、分栏和颜色均不约束后续设计，也不表示业务处理流程。
- 每图下面的字段对照表逐项使用主文档原编号和原名称，合计覆盖A01—A40、I01—I50共90项。正式页面不展示这些编号。
- 筛选、分页、按钮及文字中的操作描述用于解释功能，具体交互不在此定稿；现有HTTP限制及写操作验收见[取数与接口附件](../page-data-mapping.md)。
- 图中UUID用前8位节省空间，详情/复制使用完整UUID。全部时间默认Asia/Shanghai（UTC+8），保留原ISO值用于复制。
- 数字与状态取自既有实值；中文标题和说明为设计用译写，保留原文入口。未提供、未匹配、未关联、未配置和不可用分别显示，不填假数据。
