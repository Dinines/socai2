## ADDED Requirements
### Requirement: 内部可信的业务HTTP入口
独立调查HTTP应用 SHALL 默认信任内部业务调用，不要求登录、Bearer、API Key或角色权限；使用配置文件指定的租户与记录操作人，保留业务参数、状态和数据关联规则。
#### Scenario: 无认证信息调用业务接口
- **WHEN** 业务后端不提供认证头调用独立调查HTTP
- **THEN** 请求直接进入业务用例，查询和保存使用配置的租户与操作人，Swagger不声明认证前置
#### Scenario: 不影响内部及其它应用
- **WHEN** 独立应用采用可信上下文
- **THEN** 调查核心及内部组件不依赖该上下文装配，旧主API的既有认证行为不被更改；配置缺失不采用演示身份
