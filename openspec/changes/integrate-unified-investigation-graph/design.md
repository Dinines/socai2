# Design
按功能分析第16节实施。新增独立前端图适配和交互模块，从所选Run保存的path/chain只读归一，来源不同的谓词保留。仅同环境/租户、类型兼容且唯一自然键可对齐PG/Neo4j实体；距离2缺边不补造。postgres_fallback的Case级MAPS_TO不得作为精确告警技术关系。

左栏本次输入/链候选，右栏圆形实体、告警锚点、技术标签。选中只改变聚焦，保留节点位置和全部范围；实体反查告警，关系仅选该边两端；图层隐藏清除无效选择。分组保留真实成员和命中数。原始材料和Alert Graph范围按来源保留，无Case历史上下文明确独立于Run路径。

验证实际三输入/五候选、多来源谓词、E3缺边、降级技术、跨环境/租户、不变性、状态隔离，以及浏览器交互/布局；原前端直接回归保持。
