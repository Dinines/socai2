业务视图按字段角色构造，保留正文原值；确定排序集合。A/反馈只取实际使用的判定、理由、置信状态及建议；I保留结论、发现、问题、范围及来源业务引用，省略执行ID/时间和校验台账；H只取有效结果正文、适用范围和引用。H任务本身的身份用于对应不同人工意见，revision身份只追溯。无效输入不伪装成可用分析；有效→不可用或撤回亦能比较。

自动检查只比较当前活跃事件的I；手动check可比较本案全部适用I。为避免单纯接收指针变化触发或非活跃I新结果广播，完成/停止基线从其冻结C1恢复业务视图，再以同一当前活跃集合投影新旧两边。实际输入摘要仍对本轮完整业务视图计算，不能伪造已覆盖摘要；给通用领取器的“与某完成attempt/停止task相同”必须绑定那条真实身份，领取事务核仍是该基线。其他A/I执行器保持原摘要规则。手动范围/A变化仍参与比较；自动材料链由I有效业务变化驱动，不能因直接比较A/成员再绕过I。有效H保持独立。

容量停止按最后停止attempt的冻结策略比较相关配置；输入或容量配置变化才允许普通任务重检。配置包括Case模型输入/输出/上下文预算、查询准备和输入视图策略；不因扫描时间或一般元数据重置额度。首轮失败也登记下一检查时间，仍须7天资格和停止摘要，不能反复重做同输入。

## 上一轮比较与读取合同

程序在最终准备事务中选择同Case、whole_case/baseline、已经实际开始且本地已结束的最近Run，按started_at/id倒序；completed/failed及有结束attempt的unknown可选，未开始任务及其他Case续建前案不算。它与last_completed_attempt_id分开：后者只用于输入是否已覆盖，前者用于本轮结论比较。

只在该Run中选可用Result；没有可用结论就不可比较，不回退更早结果或当前采用判断。正常可用结论也要有可读取原范围和当前成员交集；范围更改分别记录增删成员。C6复用现有比较任务，不新增比较模型调用。运行期间人工采用变化继续受既有自动采用保护。

Case RunView/ResultView增加可空`comparison_context`，由冻结input manifest读取，HTTP仅补URL：

| 字段 | 含义 |
| --- | --- |
| previous_run_id | 实际上一轮Run UUID；首轮null |
| comparison_result_id | 该Run中实际可用且选入的Result UUID；不可比时null |
| state | initial / eligible / unavailable；eligible表示已选可用且范围有交集的前轮结论，变化结果另读change_kind/change_summary |
| reason_code | initial/eligible为null；unavailable为previous_result_unavailable、previous_input_unavailable、previous_scope_unavailable、previous_scope_not_overlapping或previous_conclusion_unusable |
| previous_run_url / comparison_result_url | HTTP按同Case真实ID补充；相应ID为空则null |

受理未执行无Run，仍从task读取；历史Run未保存该结构时返回null，不猜测或回填。新首轮保存initial，即使之后已有更多Run，读回仍不变；新后轮失败无可用上一结果仍保留previous_run_id定位。详情及已有Case历史/记录读取沿同一原件供给，A/事件/通用task DTO不改。没有模型结论时不由程序编造变化摘要。

## 周期接线与证据

Case执行配置新增显式`case.scan_batch_size`（示例100），周期/窗口沿analysis-tasks配置，总N/轮询沿统一调度配置。扫描按next_check_at/Case ID有界取数，每次推进下一检查时间；取得当前活跃事件并调用既有分配事务后再比较本案材料，有变化才登记check。没有新事件成员时不新增分配活动；续建独立initial进入同一任务队列。手动check/rerun执行前同样只补符合自动接收资格的事件成员，超期手动仅分析本案当前材料，不借此自动扩案。

自动检查、自动跟随及由此续建使用明确服务actor（用户ID为空、服务名称/版本可追溯），不借用创建人的身份伪装手动操作；原手动任务保留真实submitted_by。时长测试要求已交测试模块：6小时/7天及其他等待可在独立测试profile缩短，实际选择及默认/测试值分别记录；本步没有为该要求修改默认或测试时长配置，核心定向边界可用新夹具和显式时钟验证。

证据使用新批次/租户/UUID，实际PG/Redis与模型/来源替身分别标明，旧结束批次不重派。保存输入/比较身份、请求、原答、保存结果及HTTP读回；单点成功再集成。第6步的一项历史重复记录用例失败保留，若直接阻断本轮比较则定向修复并复验，否则不扩大专项。
