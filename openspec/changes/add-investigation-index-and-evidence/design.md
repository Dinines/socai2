# 范围与实现

GET /executions以alert_id、incident_id、case_id之一筛选，返回执行类型、范围、状态、结果完整度和原生读取地址。Case分析按保存的profile/scope或真实Case归属定位；其他记录仅凭明确raw_alert.id关联当前来源成员，旧case_id不推定真实Case归属。旧类型/完整度不确定时保留未知并跳原v1账本读取，不伪装为新版报告。按Run ID另提供单项索引读取。

在现有Case Run下增加evidence列表、按证据ID读取及rows/{index}读取。发现/逐成员判断/关联/未决问题/时间线获得证据导航；Tool证据用已存步骤的evidence_id和call_id定位准备与返回步骤，复用结果返回原证据链接。A/T/H分别保留来源告警、分诊事件及前次调查跳转。所有读取不执行模型或查询来源，既有结果工件不改写，新报告写入API相对链接。

仅验证三个业务筛选进入同一Run及证据/记录、历史查询复用链接和旧记录不混同。无新表/迁移、后台任务、厂商调用或部署。
