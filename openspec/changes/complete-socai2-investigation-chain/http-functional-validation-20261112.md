# HTTP 功能验收与后续实施

本轮承接 3.12，按负责人最新要求测试 Swagger 已实现操作，并规划未实现能力。范围只含告警、事件、调查的 43 个 HTTP 操作及已有页面所需功能；不扩展旧 AiSOC。无需另建规格或业务能力，原任务完成数保持 31/41。

## 直接验收安排

使用本机隔离 PostgreSQL `127.0.0.1:28412/v12_upgrade_dev`，复用现有 HTTP/数据库用例，创建新合成数据，保留既有记录。执行真实路由、业务服务、SQL 保存和读取；测试身份和模型/外部来源使用明确替身，不据此声称真实登录、模型质量或厂商连接通过。本批不新增真实模型调用，不部署业务代码，不启用消费者。

1. 告警/事件：列表、详情、分诊/诊断结果和历史、材料、来源及工件，核对字段含义、关联、分页、缺值和不可用状态。
2. 调查：建案、成员替换/关联/移动、分类和期限、证据发布、执行准备/启动及结果读取，检查幂等、冻结范围、保存和读回。
3. 人工任务：创建、编辑、完成、历史修订，检查正文和范围保存、旧版本保留及不自动执行调查。
4. 未实现接口确认返回 501；A/I 手动触发分别记录程序能力与真实模型成功路径的未验范围。

仅补现有用例缺失的本轮 HTTP 正常路径。不开展权限专项、全库对账、压力或恢复矩阵。失败保留原回执，修正后用新回执定向复验。

## 实际结果

**43 个操作均有本批直接请求回执：40 个已实现操作覆盖正常响应，3 个未实现操作确认 501。最终选定的 31 项功能检查通过。** 这是原 ASGI HTTP 路由、真实服务和隔离 PostgreSQL 的验证；不是 TCP/网关验收，也不是 21 生产接口全量验收。每个操作的输入、完整输出、状态码和原用例索引见 [逐项证据](../../../docs/operations/evidence/http-acceptance-20261112-01/README.md)、[机器汇总](../../../docs/operations/evidence/http-acceptance-20261112-01/summary.json)。

| 功能 | 验证到的业务结果 |
| --- | --- |
| 告警/事件读取 E22–E35 | 列表/详情、分诊/诊断与 Run 历史、材料、工件和记录关联；分页与字段对应、负责人真实名称、资产库存标签匹配、缺值/不可用及不越过主体范围。E30 的 11 类 section 均有正常读取，未做所有主体组合的矩阵 |
| Case 基本操作 E01–E09 | 建案保留成员/显式事件关系；重复 operation key 不重复创建；关联和移动保存两案范围。分类/期限和证据目录写后读取相符；成员替换真正改变当前范围，已完成任务的旧范围保持 |
| 执行与结果 E10–E18 | prepare 复用 pending；当前 C3/C6 模型替身通过原 start 路由执行、保存 accepted/uncertain 结果；六组结果字段与数据库逐值一致；报告/图工件可读；上游材料更新后历史 Run 仍读旧材料，新版本在该 Run 下返回 404；相同 start 操作不重复生成结果 |

## 首轮失败与处置

原始失败全部保留，未改写成通过。没有发现需要修改业务代码的确定故障。

| 原问题 | 原因与处置 | 结论 |
| --- | --- | --- |
| 工件大内容测试返回 409 | 旧用例硬编码大小且摘要不符；按当前读取上限构造真实大正文/正确摘要，再检查正文不返回及明确 availability | 定向复验通过；业务完整性校验保持 |
| 人工任务禁用测试意外连库 | 旧测试只关闭写开关，当前 GET 允许页面读取开关独立启用；改成两个开关均关闭 | 定向复验通过；未改服务开关规则 |
| 负责人断言失败 | 旧用例假定用户无法解析；现在读取实际用户目录，应验证名称与真实记录一致 | 定向复验通过 |
| 资产测试写夹具失败 | 原读取角色不能维护 public.assets，旧 SQL 还缺现有模型必填默认值；用显式夹具连接及现有 Asset 模型只新增本批合成资产，HTTP 仍走原受限角色 | 定向复验通过；未修改角色权限或既有资产 |
| 两个旧 Case 执行用例失败 | 旧 PipelineGateway 将当前文本模型输入当 JSON 解码，导致测试替身异常，非真实模型/业务服务错误 | 旧失败保留；新增当前合同的 HTTP C3/C6 正常流程及冻结材料读回通过。旧 JSON 替身的两个用例未整体升级，原并发等待钩子未复验；不声称全测试集通过 |
| 新增验收夹具的导入、证据角色、C3 stage 和 SQL 取值问题 | 分别修正仓库导入路径、引用登记的 `/ocsf_json/process/pid` 叶字段、C3 隐含阶段与表投影读取 | 原失败保留，最终场景通过；没有放宽生产校验 |

最终新增测试为 `test_socai2_http_acceptance_pg.py`；另修正三个已有测试文件的过时夹具/断言。每次运行记录当时源码摘要，运行期间所检查文件均未变化；不能据不同轮摘要声称整仓是一个已发布版本。编译及定向 Ruff F/E9 通过。

## 未实现部分与验收限制

[后续计划](../../../docs/investigation/http-implementation-plan-20261112.md)已按现有页面整理：先统一独立服务版本/数据目标和当前固定流程，其次管理/人工反馈、完整筛选导出、Q/采用、评论附件、探索；更新/流式沿用已有 change。资产、人员及真实审批执行交业务后端；前端交互复用现有读取；没有明确业务操作的占位项暂不扩展。

本批模型及外部数据查询为替身，只证明程序接线、状态和存储读取，不证明真实模型判断、知识合理使用或厂商实连。此前模型质量 NOT_PASSED 及主调查 31/41 保持；未通过项不能因本批 40 个接口正常响应而核销。生产只核配置，业务代码未部署、提交、推送或更新父项目。
