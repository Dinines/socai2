# 先收口固定范围的一次调查

2026-11-12，负责人明确“先做好固定的调查流程，然后再推进更新、流式的调查流程”。本计划属于现有主 change，复用原任务编号和规格；不另建固定调查任务树，不将已有局部成功或规划写成整体完成。

## 当前范围

固定一组告警和一个事件，先完成其 A/I，再显式创建并启动一个 Case。本轮成员、材料版本、调查窗口、已选人工材料和配置保持固定，从 C1 到 C6 生成保存结果并读回。人工材料如在开始前已存在，按原范围/版本纳入；中途新反馈触发重算、成员自动跟随、队列与自动消费均不纳入本轮。

主链是：**固定材料 → A 单告警分诊 → I 事件诊断 → C1 冻结 → C2 补充背景/知识 → C3 主分析 → C4 必要直接查询或问题级 Deep → C5 来源关系 → C6 综合结论 → 保存/读取。** A/I/C 是有明确入口的数据依赖，不以执行一次作业冒称自动串联已启用。Deep 只在当前问题需要时执行；没有必要补查时直接综合，不为走齐节点增加模型调用。

## 知识与固定母版的结合

固定母版分别规定 A/I/C3/Deep/C6 的业务目标、来源角色和输出；程序填充当次材料，不把大量检索结果拼成另一套提示词。当前知识消费集中在 Case：

- **技术解释**帮助解释已有行为的含义和条件；**取证指导**帮助提出可验证的问题和需要的日志；**历史参考**帮助比较相似处及差异。共用现有存储，按目的/适用条件筛选，均不能证明本案已发生、已获授权或已处置。
- C2 取得候选，C3 按本案选入；Deep 只拿当前问题相关片段和必要引用；C6 只拿必要前序依据及影响综合的条目。A/I 本轮不扩展新知识检索。
- 必要观察、人工原文、前序依据优先，知识按身份/版本去重并受现有配置预算限制；不改写正文、不用相似度作事实置信度、不丢相反材料，不为了填满数量循环补搜。
- 复用已有检索/索引，不再新增知识总结模型。分开记录检索命中、实际输入、模型引用以及是否合理影响问题/判断；模型未使用不写成已发挥作用，也不硬性要求为引用而引用。
- 历史卡沿已交付规则：有效且对应材料的 A 判断保存/采用后按配置同步；原始告警或 Case H 本身不直接入库。异步排队维护属于后续流式 change，本轮不改。

## 本轮实施范围：固定链路知识引用

2026-11-12 继续实施，限定于原 3.10/3.14/3.30，不实施流式任务。只读复查 `knowledge-selection-20261112-01` 原件发现：C3 为 A3 成员解释同时引用本案观察及相关历史卡/历史分诊/人工正文，接收器因历史来源 `alert_ids=[]` 一律报 `source_member_mismatch`；指令允许有归因的历史比较，但接收器没有区分辅助参考与本案成员依据。C6 最终缺 A3 依据的拒收仍成立，不能靠放宽覆盖规则修复。

最小修正：已通过目的/适用条件选择的知识，可在其查询适用成员的解释、非 observed 推理或补查理由中作为辅助引用；原历史主体/角色保持，所有知识均不计入成员依据覆盖。C3/C6 接收、局部保留和纠错提示采用同一判断；仅历史知识不能撑起已分析成员或最终覆盖，observed/冲突仍只用本案直接观察。顺带修正合并知识的选择：目的与成员关联必须来自同一检索出处，不能把 A1 的技术用途和 A2 的方法用途拼成 A1 的取证指导。

不修改 A/I 公开字段、结果表或历史原答，不增加模型调用/纠错次数。验证只补知识辅助引用/覆盖拒绝及同出处筛选的直接断言，再用原服务执行一条固定 A/I→Case→保存读取路径；真实模型和模板回复分别说明。历史失败不会重派或改写，最新执行回执另存本批目录。

同批固定流程另外定位 A2 输入阻断：实际配置模板仅 34,458 字节/140 来源，但构造器先校验未使用的旧 JSON 消息，73,726 字符触发旧 60,000 字符上限。补修只分开来源构造和旧消息渲染；原始字段安全检查、保留/准备上限及实际发给模型的完整消息检查保持，不提高阈值或截正文。对已保存输入离线重建和定向检查，不重派失败 A2；A1 重复引用、I 成员引用错位的原答拒收保持。

该批 C6 第二条建议为空引用，接收器按原规则拒收，但生成 Schema 尚允许空数组。补齐建议至少一个非回执来源的生成约束，与原接收语义一致；只做直接 Schema/解析断言，不新增纠错次数，不给原答补引用，不再次采样。

实施完成后的独立结束审计、统一发布及归档沿项目原规则，不由本文件提前声明完成。
