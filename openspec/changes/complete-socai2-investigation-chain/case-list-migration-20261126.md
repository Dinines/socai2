# Case列表、预览和公共框架迁移第一步

## 本步目的和范围

负责人在审阅完整调查规划后要求开始推进。本步沿总规划P1和页面迁移顺序，完成8181 Case队列、右侧预览及同案公共页头/导航的对齐，使用已有数据核对显示和读取。不在本步生成主机场景、重派调查、创建Case或修改既有案件事实；新建首轮及管理写入的真实闭环仍按P2/P3验收。

本步是第一组页面的迁移及已有数据读取步骤，不将11个F编号全部标为端到端通过。新建/管理入口、表单展示及直接受影响的请求/回执接线属于本步；真实保存/首轮生成、结案/重开的验证保持后续任务，不使用占位或假成功来隐藏缺口。

参考：[总规划](investigation-test-plan-20261126.md)、[逐页理解](investigation-page-migration-checklist-20261126.md)第一组、[88项矩阵](investigation-test-matrix-20261126.md)。4173完整页面及后续已确认业务规则是目标，不能因复用旧组件而保留无依据的旧布局。SpiritHub外层导航保留所属产品边界，不修改无关模块。
