## 字段与交互缺口

- 正式记录当前缺事件独立资产总量。库存分区总数是对象与资产间的匹配边数。成员负责人缺名称，对象缺风险等级和资产业务域，活动缺通用触发方式。这些位置显示未提供或已知来源。资产 ID 仅随实际匹配边出现。
- 图将相同命名空间、类型和对象键合为同一对象，提供按类型排列。4173 的相似节点分组开关、历史图状态、潜在路径及攻击因果缺少本页来源或对应交互。时间进度从已读事实重放，数据来源仍是当前材料。
- 成员告警、对象、活动的搜索以及成员日期作用于已载入范围。4173 全量筛选、排序、导出、页码和选择操作缺少本页对应实现或合同。对象目录展示已载入的对象类型，活动序号沿接口返回，无全局最近活动排序。
- 已发布诊断与最近已有 Run 可分别跳转。诊断历史分页的列表入口、尚无 Run 的任务、发起诊断、冻结范围和覆盖明细沿事件阶段的后续调查交付处理。
- 21 真实有值数据、管理保存及活动读回、诊断生成、Case 联验及真实库存匹配正例待事件联调。
