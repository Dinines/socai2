## 本步确定的摘要合同

新增 `GET /api/v1/socai2/cases/{case_id}/info-summary`，只允许读取。响应字段：

- `case_id`、`scope_revision`、`observed_at`：同案范围和本次读取时间。
- `member_object_count`：全体当前成员最新材料的 `(namespace, object_type, object_key)` 去重数。
- `object_preview`：相同组合稳定排序前4组，组内最小真实 object id 为代表；每项 `object_id, namespace, object_type, object_key, raw_value, alert_id, material_id, source_path`。代表来源是一个真实来源入口，不声称包含该对象所有引用。
- `members_without_current_material_count`：当前成员尚无可读当前材料的数量，供对象/战术覆盖提示。
- `activity_time_from`、`activity_time_to`：全体当前成员 `event_time` MIN/MAX，未知保持null，不用入库/更新时间补。
- `tactics`：复用 `TacticCount(label, alert_count)`，从成员当前材料 `detection.tactics` 的非空字符串按标签 `COUNT(DISTINCT alert_id)`；一告警可在不同标签各计一次，空列表不能替代读取失败。
- `investigation_count`：与无筛选历史目录相同合法关系范围的一Run一行 COUNT，复用 `StoryRelations` 与合法显式Run引用准备，不执行cards、investigation_refs、逐Run回执或详情。

成员数、独立证据、采用判断和管理事实继续使用 E03，不扩写其来源意义或修改告警DTO。摘要只使用当前 Case 成员及其最新材料，租户边界和既有只读事务保持。缺案404、读失败503按既有原生错误处理；不创建资料、补对象或回填历史。平台新增一条普通GET与DTO，走本机原生候选配置，保留其它路由；E03实际父身份只做一次定向核对，若已正确直返则不改该路由。
