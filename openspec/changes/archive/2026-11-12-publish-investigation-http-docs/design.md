# 设计

用 OpenAPI 3.1 JSON 描述合同，Swagger UI 展示接口及请求/响应示例，静态 HTML 展示 125 项功能和调用组合。原始导出文件保留为来源，交接包是附加说明的发布版本，不改变业务合同。

官方镜像固定摘要；Compose 使用显式 env profile 指定镜像、绑定地址、端口和文档目录。本机绑定回环，21 绑定现有内网地址；文档无数据库或凭据挂载。浏览器可自行填写可达的 API 地址，不做代理、不扩大业务 API 的监听范围。在线校验器关闭，文档不依赖外部 CDN。

所有示例标明合成合同示例，不能当成真实执行或模型质量通过的证据。接口状态按已有代码与既有发布证据说明；本轮不执行业务请求。A/I 执行开关未重新核验，不能宣称生产已开启。Q 问答、保存、采用三项以真实 501 返回展示。

只做文档服务直接读回和独立交接审阅；不开展权限、模型、业务 API 或数据库验证。不提交、推送或更新父项目引用。
