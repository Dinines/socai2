## Why

本 change 承接主调查 3.7/3.12/3.16 的 Case/H 正常 HTTP 操作子范围。基线 `V1.1@97953643`，21 为 `v1.2-20261111-r1`。建案、prepare/start、人工任务及版本的服务实现已存在，但 HTTP 依赖仍统一使用只读 `aisoc_app` 连接，`SOCAI2_CASE_API_ENABLED=false`；按需处理和服务层测试不能证明这些写接口已经可用。

沿用已完成独审和前轮证据。M01-A/M01-B 继续后置，模型质量 NOT_PASSED；不通过重复采样要求本次接线证明全部语义质量。

## What Changes

- 为 Case/H HTTP 写操作显式配置现有处理连接，GET 沿用现有读取连接；缺少配置时明确失败，不静默换库或改用读取身份写入。
- 既有发布入口从受控处理配置生成 Case 连接并开启当前写开关，保持认证主体、租户、现有 API 字段和预算。
- 本地用一条 HTTP 建案→首次调查→人工补充/修订→显式准备及启动后轮→读取闭环，直接核所选人工版本、持久化及返回关系。
- 更新写接口交接、配置说明、问题状态和运行记录；完成限定独审后统一发布一次、核实际接线与少量写读，再归档及同步 Git/父项目。

## Capabilities

### New Capabilities

- `case-human-http-flow`：显式运行连接下的 Case/H HTTP 写读及人工版本交接。

### Modified Capabilities

无。不变更告警交接字段、数据库表列或既有请求/响应结构。

## Impact

范围为 API 配置/会话选择、Case/H 路由依赖、运行配置生成与交接。复用已存在的 `socai2_prod_processor`，普通读写接线随功能完成，无新权限设计、通用执行/测试框架、自动消费者或响应动作。模型输出质量与产品页面是否接通分别记录；本 change 不核销主调查整体任务。
