# 审计方法
以已确认的层级分工为基线：告警解释单条检测与处理，事件展示多告警及关联，Case组织研判材料和协作，Run保留固定输入下的过程与结果。按可达页面检查每项功能对用户判断/操作是否有独立价值，区分重复展示、入口冗余、职责冲突与后端接入细节。完整演示与实际保存案例交叉查看，不因真实缺值否定有业务价值的功能。
