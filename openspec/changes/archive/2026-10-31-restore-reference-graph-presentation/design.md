# Design
以 V1 workspace-view.js / styles.css 的微软参考图谱为视觉来源：白底、细灰线、圆形图标、蓝色聚焦、左告警与右详情。最新版数据投影和选择语义保持；告警锚点与技术映射仍可在画布点击，不删关系、不合并缺失身份、不补中间边。

自动布局改为稳定的中心实体与外围节点分布，分列布局保留。布局只依赖同 Run 原始节点，不随点击/图层筛选跳动。更小容器将详情移到下方，并保留画布滚动和可读节点尺寸。分组、候选、图层、技术、边详情、缩放和来源材料继续可用。

改前三个前端文件及hash保存在 .local/versions/graph-presentation-before-20261031。验收采用现有7项图谱合同、必要的坐标/缩放检查和真实浏览器视觉与交互检查；结束独审限定本批呈现改动。
