# 设计
四卡统一计数 Case；可处理范围为 New / In progress，未知状态不推断为未解决。待分配为明确“未分配”或空负责人；处理中为 In progress；高严重程度为高；待人工跟进为至少一项 New / In progress 的任务。同一 Case 在单卡只计一次，多卡可以重叠。
以全部已加载案件为基数，不随表格筛选变化；info 明确范围和可重叠。点击卡片替换已有搜索/日期/字段/指标筛选，保列设置与排序；再次点击或移除芯片取消该指标；其后可叠加普通筛选。筛选集保存该指标并兼容旧筛选集。所有来源共用规则，不写业务记录。
# 验收
检查闭合案件排除、任务按案件去重、稀疏状态不推断、卡片与列表一致、清除/筛选集兼容、宽窄布局。只跑受影响前端直接测试，独立结束审阅后归档。
