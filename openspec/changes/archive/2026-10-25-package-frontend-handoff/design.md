# 设计

根目录 index.html 就是当前原型入口，所有 CSS、JS、SVG 均相对引用。serve.py 原样附带，作为双击 HTML 之外的可选本地预览方式。README 指明告警、事件、Case 的 hash 路由；guide.html 提供页面和文档导航。

数据保留原52条样例和追加6条实际处理结果；导出只供查阅的 JSON，不改网页运行方式。字段说明以已确认口径为准，原详细讨论作为带时间边界的参考副本。原文指向包外仓库源码的链接转换为参考路径文字，避免接收方误点。

打包使用明确文件白名单，不包含 .env、凭据、模型提示词、完整私有数据库快照或清理命令。源代码副本按 SHA256 核对；接收方无需后端、Node 或 npm。仅打包工具渲染 Markdown 时使用本地已有 markdown 库。

验收：源文件一致、数据数量及关系、相对资源/文档链接、迁移到临时目录后浏览 HTML 与主要路由。浏览器交互仍是原本地状态，服务端不在本次验收范围。
