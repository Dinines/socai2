# 发布三类功能与已审计 HTTP 文档

## Why
负责人已授权把本轮补齐的交接内容同步到本地和21 Swagger，按告警、事件、调查集中展示，逐功能明确接口、输入输出和实现状态。

## What Changes
- 继续使用原125项功能（22/15/88）和43个操作，功能目录与Swagger均按三类组织，共用接口可出现在多个分类。
- 发布已审计的522个固定输出字段出现位置及28组动态结构，保留具体投影、统计、错误、未实现和未核实边界。
- 更新文档生成器和静态包；本机ARM64与21 AMD64继续使用既有独立文档容器及镜像。
- 只读取文档页面和容器状态，不改业务代码、不调用业务API/数据库/模型，不提交推送或更新父项目。

## Impact
纯文档和文档部署，无规格级业务变化；沿用 investigation-http-documentation 规格。旧审计批次保留原时点，当前发布状态在根交接与回执更新。
