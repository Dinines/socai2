# 统一调查 HTTP 服务入口

2026-11-12，负责人要求按 OpenSpec 规划并推进。复用本 change 承接独立 HTTP 入口，不复制主调查任务树。原2026-10-28的隔离服务交付保留为历史阶段；本阶段对应主调查3.12和[后续接口计划](../../../../docs/investigation/http-implementation-plan-20261112.md)的首项。

## Why

实际问题：正式主API18000有41个调查操作；旧独立API18020有36个操作并连接旧隔离库。当前独立应用代码已有43个操作，但启动器禁止选择正式库，手动A/I仍使用通用读取连接。前后端无法按一个当前合同连接同一套数据。

## What Changes

本阶段目标：提供明确配置的独立正式入口，完整挂载43操作；认证/读取与调查写入各使用已有连接，启动时验证同一目标。先本机真实HTTP+隔离库直接验收，再限定独审、一次发布独立服务并读取验收。正式服务复用已部署业务镜像，仅覆盖本阶段入口/连接修复，不把并行未发布的模型改动一起发出。保留旧服务和数据，标为历史入口；不启用消费者，不新增真实模型采样。

不新增业务字段、数据库表、Q实现、资产维护或真实响应。E19–E21保持501；模型质量NOT_PASSED保留。其他明确功能按主调查的HTTP路线逐项推进，本 change 不提前实现全部远期功能。
