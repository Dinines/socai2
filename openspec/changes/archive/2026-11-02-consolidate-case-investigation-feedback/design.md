# Design
复用所有Case共用的case-workflow与investigation-workspace组件，不按来源分支。任务中的来源调查承担整轮回查；补充资料只提供具体证据和工件，历史已选引用继续保留。打开或取消表单不写记录。
概览先显示本案活跃Run（沿既有归属规则）与草案，再展示已有结果。草案历史折叠但数据不删。
统一只读runMetrics：总耗时仅用有效Run开始/结束差值，不用Deep latency；工具记录数是已保存条目数，不冒称实际调用总数；模型调用及tokens只取已有数值，缺值为未记录，零保留。历史/详情共用。
唯一PRD保留当前预览事实，新增反馈结算与目标设计，逐项标记用户明确方向和本次建议，生产实现未接部分不进入已交付主规格。
