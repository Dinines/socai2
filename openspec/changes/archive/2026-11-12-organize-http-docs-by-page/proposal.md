# 先厘清功能，再审计 HTTP 合同

## Why

负责人认为当前功能、接口现状与展示改版混在一起，要求先按现有页面设计同步需要的功能，再审计接口用途、输入、输出及每个输出字段。

## What Changes

- 以现有125项功能和D01–D07确认规则为产品基线，集中为告警、事件、调查三类；直接完善原功能清单，不另建相互冲突的需求清单。
- 对43个现有HTTP操作做静态合同审计，核对路由、DTO、读取/写入装配和历史交接，逐字段注明含义、来源、空值、枚举、限制及差异。
- 单列功能缺接口、组合调用、错误文档及输出不够明确之处；未知不猜测。
- 本轮暂停展示改版和发布，不修改业务代码、字段、数据库，不调用业务API/模型或做权限验证。

## Impact

仅功能及交接审计文档。已发布docs1继续保留，不将本地待审稿写成线上已同步。不扩展旧AiSOC功能。
