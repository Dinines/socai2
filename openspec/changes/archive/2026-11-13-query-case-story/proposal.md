# Why

F20-01/02/05要求集中阅读案件事实、调查和人工完成结果。目前调用方只能分别读取并筛选已加载片段，不能对整个案件故事搜索或连续分页。负责人已暂缓AI对话，本change只推进普通故事读取。

# What Changes

- 新增只读 GET `/api/v1/socai2/cases/{case_id}/story`，聚合当前成员告警、基础调查Run及其已存结果、人工任务已完成修订。
- 按真实业务时间倒序、缺时间置后；支持关键词、告警等级与稳定游标分页，返回来源身份用于原接口回查。
- 对外路由、用例端口与内部只读用例分开。复用现有字段，不改告警合同、表或调查流程，不生成新结论。
- 直接验收、独立审计及HTTP交接一次完成；AI对话、探索和自动调度不在本change。

# Capabilities

## New Capabilities
- `case-story-query`: 案件故事全量范围检索及分页。

## Modified Capabilities
无。

# Impact

主调查3.12的独立子范围。原64操作保持；新接口不写数据、不调用模型、不引入核心对HTTP的反向依赖。并行模型修改保留，不纳入本项发布。
