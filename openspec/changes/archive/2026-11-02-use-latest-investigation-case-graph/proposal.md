# Why
用户要求案件图使用最近一次完成调查的图谱，替代只有当前成员关联的单薄呈现；同时要求设计案外关联告警的查看与加入入口，澄清全部关系和链候选含义。
# What Changes
案件图默认最近已结束调查（含明确标识的部分交付，排除仅分诊/运行中/失败），显示来源/时间/原输入范围。没有完成调查时保留当前成员关系；有调查但缺图不借旧轮伪装。保原Run图并解释来源上下文。关联告警列表去重排除本次输入，状态区分空结果/未保存/不可用；选中后右侧显示当前Case归属和关联依据，可经原本地添加表单确认加入。
# Impact
仅V2本地页面、直接测试、交接。覆盖前批Case图仅当前成员的呈现决定；原源数据/Run/后端/模型/部署/Git保持。不是改后端Graph查询算法，不将多个Run合并，不自动启动调查或移动其他Case成员。
