# Design
使用现有forCase同源/保留Run集合，筛选status=completed且非not_escalated，以ended优先、缺失时started排序，缺时间排末；标题明确时间字段。partial仍是已结束但明确显示部分交付。只选最新一轮，不按材料丰富程度跳到旧轮。无已结束调查使用当前成员图；有该轮但无材料显示本轮缺项。案件图复用Run图圆形/来源交互，默认全部已保存关系；AiSOC上下文只按该轮输入取保存对象，不混入后来成员。

关联告警列表取图中非Run输入告警，按候选分数优先排序并保图来源；本次输入和其他关联告警不重复。原候选返回保持在来源材料中。不再把缺失/失败折成0，不把关联数量当攻击链成立数量。左列表/中图/右详情联动。右侧区分本轮输入与当前本案成员，已有其他Case只显示归属，不移动。加入本案打开既有同源校验表单并预选一条，确认后仅本案并集追加、留活动；返回原图查看位置，历史输入与原关系不改。无可用原告警或源不匹配不提供添加。

不新增模拟真实图谱结果；保留最新数据和历史原件。宽窄屏浏览只读/取消，写操作在直接隔离测试中核对。

复用本轮图时同时接入已保存Alert Graph的一跳邻居及明确关系类型，标注其方向未记录；多跳可达节点因缺完整边不强行连入画布，仍在来源材料查看。去重保留每条关系的来源。
