# Why
用户确认案件图谱探索、草案与执行状态功能并要求详细整理、构造mock数据后实施；追加替换无价值多告警占比卡为处理中的Case。
# What Changes
案件图基础只含本轮Path/直接邻居；告警与实体可扩展，战术技术只查看。右侧排序候选、预览/展开/再扩展/撤销/保存探索/准备草案；与成员关系和历史Run分开。草案可取消，Case页头持续执行提示，单Case单活跃Run。多事件选择与关联资料保持。两套独立演示案件覆盖空闲探索与运行中下一轮草案；本地模拟启动明确标识。
# Impact
仅prototypes/security-pages-v2及设计交接，不接后端、模型、真实运行或部署；AiSOC保存原件与旧样例保持，不提交推送。
