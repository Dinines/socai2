# Design
复用圆形三栏图与当前Case流程。新增独立探索模块，默认同轮Path+AlertGraph直接边，不自动把Chain候选铺入；Case无完成Run时当前成员图支持相同探索。实体/告警扩展只查当前载入的同源告警记录；历史保存候选与原分数继续在来源材料中查看，不补齐成完整告警库存，不发后台；默认显示5，展示关联依据与时间、排序仅供关联参考。通过共享对象画真实直接连接，未知/只有历史候选不能补造关系。每轮扩展保起点/新增节点/连接，可预览、展开、撤销；节点紫色区分新增，选入草案用勾选，技术仅分类高亮。保存探索按Case独立保存，不改Run，恢复须保原基础来源/范围；新完成Run到达时不静默串底图。
草案保调查目标、成员选择、实体补查对象、图谱来源和范围。案外告警明确提示需加入并经保存草案确认后并集加入；取消不加入。已保存草案可取消（留记录），同一草案可编辑；已启动/取消草案只读。非演示真实Case启动禁用，演示Case以明确“模拟启动”创建独立localRun，冻结选材与来源，示例进度按手动推进，不计真实模型或补造实际报告。每Case仅一个pending/queued/starting/running等活跃或待确认Run，重复启动复用/阻止；成员编辑与图扩展不改它。最新完成Run不被运行中替换；历史Run图只读，入口可跳回Case探索。
Case关联事件由显式选择及成员所属事件共同呈现，支持多个。成员集合去重，不移动其他Case/事件；单独添加告警不宣称整个事件全部入案。页头事件过多可折叠，详细信息列清单。Case列表第四卡按处理中状态计数。
新增两Case/三事件/十告警和对应图谱、一个已运行的演示Run、两已完成参考Run、待启动及取消草案，独立来源字段/ID，初始化仅追加不覆盖历史编辑。覆盖连续扩展、超过5候选、重复发现、无法扩展技术、案外完整告警加入、空结果、执行互斥、取消和多事件。外部真实记录不补值。
