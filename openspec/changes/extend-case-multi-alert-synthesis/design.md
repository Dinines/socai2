# 实现约定

模型输出增加member_assessments、relationships、open_questions，均携带适用成员和证据引用。服务端核对成员属于选定范围、证据存在且逐成员判断引用自身告警材料。未返回判断的成员保留not_assessed，读不到材料的成员保留source_unavailable；未决问题使报告保持partial。

时间线由程序从告警时间和成功Tool返回的记录时间构造，保留证据编号、记录下标及范围内外标记。产品主机读取使用observed_at并标为当前快照，不能伪作历史行为；无时间记录保留未知。共享主机仅产生候选成员归属，不代表因果关系。

新字段进入现有结构化结果和Markdown。旧报告读回不改写，缺少新模型字段不伪造完成；适度增加单次模型输出上限以容纳三成员实例，总调用次数、工具和总Token预算保持。直接验证两条相关告警加一条背景告警，以及遗漏成员/不合法引用的结果。
